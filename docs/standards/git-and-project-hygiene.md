# Git and project hygiene

> Commit and repo hygiene: small focused commits that explain why, no dead code, tidy config.
>
> Status: accepted · Version 1

## Git and project hygiene

- **Small, focused commits**: scope commits and PRs to a single responsibility.
- **Commit messages explain *why***: not just what changed, but what motivated it.
- **No commented-out code**: delete dead code — git history is the record.
- **Tidy configuration**: keep linters and formatters current; no unused config or scripts.
