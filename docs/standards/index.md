# Standards

Coding standards every agent must follow before writing or modifying code in any personal repo.

## Docs

- [Code style and formatting](code-style.md): Personal style rules for all repos: functional/hook-driven code, formatting, naming and readability.
- [Git and project hygiene](git-and-project-hygiene.md): Commit and repo hygiene: small focused commits that explain why, no dead code, tidy config.
- [React standards](react-standards.md): React rules: one component per file, no inline JSX callbacks, styles, maps or object props.
- [Structure and architecture](structure-and-architecture.md): Single responsibility, barrel-only index.ts, import and export rules, shared libraries, testability.
- [Type safety](type-safety.md): TypeScript rules: no any, named shapes only, import type, explicit returns, nullish idioms.
